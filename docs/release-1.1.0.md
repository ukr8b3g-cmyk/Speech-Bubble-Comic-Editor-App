# Speech Bubble Comic Editor App v1.1.0 — Windows x64

背景削除の標準モデルをInSPyReNetに変更しました。従来のisnet-animeも、同じ画面で引き続き使えます。

1. 画像を選んで［背景削除］を開きます。
2. ［背景削除方式］でInSPyReNetまたはisnet-animeを選びます。未取得の場合だけ、モデル名とサイズを確認してダウンロードします。InSPyReNetは約377 MiB、isnet-animeは約168 MiBです。
3. プレビューを確認し、必要に応じてマスクを補正して［適用］を押します。一枚画像では、元画像を保持したまま切り抜きが透過レイヤーとして追加されます。

以前に取得したisnet-animeはそのまま使えます。画像の処理はPC上のCPUで行います。
