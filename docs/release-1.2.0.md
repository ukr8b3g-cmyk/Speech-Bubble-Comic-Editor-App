# Speech Bubble Comic Editor App v1.2.0 — Windows x64

一枚画像・縦4コマ漫画・コミックの3画面に、レイヤー付きPSDの書き出しを追加しました。上部の［画像を書き出す］の右にある［▼］から［レイヤー付きPSDを書き出す］を選んでください。

PSDをPhotoshopで開き、たとえば「セリフ・文字 · こんにちは」のレイヤーを非表示にすると、人物と吹き出しを残したまま、そのセリフだけを消せます。縦書きや文字の縁取りは画像レイヤーとして保存されます。文言の変更には元の `.sbeproj` を使ってください。
