# Speech Bubble Comic Editor App 1.0

Windows x64 standalone release. Application and installer display version: **1.0**. Internal application version recorded in project metadata: **1.0.0**. The project archive format remains version **1**.

This App is the standalone successor to [Speech Bubble 4koma Editor](https://github.com/ukr8b3g-cmyk/Speech-Bubble-4koma-Editor). It brings comic editing into a Windows / pywebview application with three independent workspaces: Single Image, vertical 4-Panel Manga and Comic with a free panel layout.

## Editing in 1.0

- Add image layers or place shared Page Images in panels; adjust non-destructive crop, scale, rotation and opacity.
- Add speech bubbles, text with horizontal or vertical writing, SFX, stamps, frames and emphasis lines. Edit layers, alignment and custom presets.
- Create a vertical four-panel page or split, merge and adjust panels in the Comic workspace, including diagonal dividers.
- Use Quick Retouch, black-and-white comic conversion and local AI background removal. Background removal requires a separate first-time model download.
- Save all three workspaces and project images in `.sbeproj`; export the active workspace to PNG / JPEG / WebP, with optional Overlay PNG.

For a first project, choose a workspace, add images, place bubbles and text, then use **Save Project** to create a `.sbeproj`. **Save Layout** / Ctrl+S saves the local editing layout; it does not update a `.sbeproj` file. **Export Image** renders the active workspace. See the [README](https://github.com/ukr8b3g-cmyk/Speech-Bubble-Comic-Editor-App#readme) for detailed instructions.

## UI language and artwork

Japanese and English UI are available in Settings. **Most bundled onomatopoeia/SFX and stamp artwork remains Japanese.** Switching UI language changes controls and catalog labels; it does not translate or redraw text inside images. Work on English artwork variants has not started. User dialogue and custom asset names remain as entered.

## Changes

- Localized all 190 built-in SFX and 94 stamps by stable asset ID. Cards, layers, tooltips, accessible names and favorites now use the same name in the selected language.
- Japanese SFX and stamp artwork is preserved. English SFX names use the written pronunciation; descriptions are added only for clear meanings. Ambiguous sounds retain their pronunciation.
- Search retains Japanese names, English names, aliases and keywords. Name sorting follows the UI language. Dynamic catalogs preserve their supplied English names.
- Localized save, draft, export, font-loading and failure messages, unsaved-change prompts, text properties and image-tool hints.
- Regenerate the bubble library on language changes and opening, including the empty My Presets help. Localized image crop, basic symbol and multi-selection alignment properties.
- Kept user dialogue, user asset names, serialized IDs and the existing `.sbeproj` format.
- Aligned application, package, Windows version resources, setup filenames, README and CI with 1.0.

## Current limits

- Fonts are referenced by identity and are not embedded in projects; install the same fonts on another PC to reproduce text appearance.
- Workspaces are independent; direct layer transfers between modes are not supported.
- User presets for canvas background patterns are not supported.
- Local background removal runs on CPU after its model is downloaded.
