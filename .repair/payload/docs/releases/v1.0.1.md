# Speech Bubble Comic Editor App 1.0.1

保存安全性・カスタム素材・Overlay書出しの修正版です。Windows x64 / pywebview、3つのワークスペースと既存プロジェクト形式を維持します。

## 修正

- 別プロジェクトを開く直前に未保存状態を再確認し、キャンセル・保存失敗では現在の編集とUndoを保持します。
- レイアウト／プロジェクト保存は送信したスナップショットだけを保存済みとして扱います。待機中の追加編集や、別ドキュメントの状態を解除しません。
- 分離パレットによる編集をメイン画面の未保存・Undo・下書き処理へ通知します。別ドキュメント宛てや古い順序の通知は適用しません。
- 使用するカスタムスタンプ／SFX画像を内容ハッシュで`.sbeproj`へ同梱し、別ポート／別PCで読み込めるようにしました。元のプリセット名・スタイル・一覧は上書きしません。
- Overlay設定をPNG／JPEG／WebP書出しへ反映します。Overlay自体は透過PNGです。素材の読込に失敗した場合は書出し前に通知します。

## 最適化と互換性

大画像の寸法をピクセル展開前に検査し、重い書出しをHTTPイベントループから分離します。同時の全画像書出し数を抑え、キャッシュを枚数と推定ピクセル容量で制限します。速度・総メモリの一律の改善保証ではありません。

旧`.sbeproj`の読込は維持します。素材が同梱されていない旧ファイルは、元のカスタム素材が別途必要です。フォントは同梱しません。新形式の素材情報はarchive version 1のoptional metadataで、旧版による完全な可搬性は保証しません。旧v1.0の配布物・タグは変更しません。

Save Layout / Ctrl+Sはローカルの編集レイアウト、Save Projectは`.sbeproj`です。レイアウトだけの保存ではプロジェクトファイルを更新しません。

## Validation scope

Automated Python/JavaScript regressions and Chromium tests with the real local Desktop HTTP API run in the linked build. Native file pickers are represented by deterministic test bridges. Windows setup build, checksum and silent install/uninstall checks are separate from browser validation. Native WebView2 interaction, clean Windows 11 desktop acceptance, ONNX inference and subjective artwork quality are not claimed as newly verified.

Version: app/display/project metadata **1.0.1**; Windows file version **1.0.1.0**. The installer and portable ZIP are generated from the same reviewed source commit. Verify downloads with `SHA256SUMS.txt`.

## English summary

Protect unsaved edits before opening projects and during asynchronous saves, track detached-palette changes, embed used custom stamp/SFX artwork for portable projects, and honor Overlay export settings. Keep all three workspaces, existing projects, and user preset libraries. Limit decoded-image cache retention and run heavy export work off the HTTP event loop.
